A bridge for local tasks.

Task Forge Relay connects Stephen Jones’s Google Sheets task mailbox to his TaskForge scheduler running on his own computer.

Google Sheets mailbox↔Local TaskForge↔Task results

What the relay does

The relay reads queued task instructions from a configured spreadsheet, submits validated tasks to the local scheduler, and writes delivery status and selected task reports back to that same spreadsheet. Delivery receipts help prevent the same request from creating duplicate tasks.

Why it requests Google access

Google Sheets access lets the relay read its mailbox and update task status and reports. The Google permission covers spreadsheets broadly; the relay is configured to use one mailbox spreadsheet. Offline access lets it continue working without an interactive sign-in for each poll.

This is a personal-use utility, not a public sign-up service. This website provides app information only. It does not provide access to the relay, its spreadsheet, or the local scheduler.
